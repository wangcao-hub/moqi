              编程 agent
              
正在找这台电脑上的编程 agent…

              

              

                
                每个任务最长
                
                
                分钟
              

              
任务在单独的分支和工作区里做，你点「合并」之前不碰项目目录。agent 只能改工作区里的文件、只能跑你列出的命令。Claude Code 的命令在它的沙箱里跑，不允许联网时连不上网；Kiro 会拒绝没列出的命令，但列出的命令能联网。

            

          


          

            其他 agent
            

              moqi 在这台电脑上找到的 agent。接入后，它们能通过 MCP 读到 moqi 对你的了解、把了解到的告诉 moqi，也能通过 moqi 提醒你。点了才会改，改之前先备份。
            

            

          


          

            MCP 工具
            
moqi 能用的 MCP 服务器。服务器标了只读的工具随时可用，会改动东西的工具每次先问你。

            

            

            
会改动东西的工具

            
外来的写工具默认每次都先问你。可以逐个放开，也可以按来源整组放开；放开后直接办，但这一轮读过网页、文件或别的 agent 的消息时，仍会先问。

            

            
普通动作

            
新建、移动、改名这类不覆盖、不删除东西的动作。连着同意 3 次后 moqi 也会问你要不要直接办。

            

            

              手动添加
              

                
                
              

              

                
                
                
按空格分开参数；带空格的参数请改配置文件。
